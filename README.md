# Web Development

A collection of HTML, CSS, and JavaScript practice files and mini projects, built while learning web development fundamentals through the Sigma Web Development course.

## Contents

| Folder | What it covers |
|--------|----------------|
| `HTML 1` to `HTML 13` | HTML structure, forms, media (images, video, audio), and small JavaScript-powered pages |
| `CSS 1` to `CSS 5` | Styling, layouts, and page design with CSS |
| `HTML 4/bookmarkmanager.html` | Bookmark manager mini project |

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Git & GitHub
- VS Code

## What I Learned

- Building page structure with semantic HTML
- Styling pages with CSS (selectors, box model, flexbox)
- Handling forms and user input
- Adding interactivity with JavaScript and DOM manipulation
- Embedding images, video, and audio in web pages

## How to Run

1. Clone the repository:
   `git clone https://github.com/devsinghrajpootd007-blip/sigma-web-dev-course.git`
2. Open the folder you want to view.
3. Open `index.html` in your browser (or use the Live Server extension in VS Code).
